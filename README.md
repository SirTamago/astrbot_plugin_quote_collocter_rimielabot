# AstrBot 群友语录插件

什么？群友又爆典了？当然是截图保存让他名垂千古口牙（

截图投稿群友的逆天语录，发送 `/语录` 或戳一戳机器人随机抽取一张。插件按明日方舟同款的 1~6 星稀有度做独立随机抽取（6★ 2% / 5★ 8% / 4★ 50% / 3★ 40%），支持保底、短期去重、投稿记录、回复式管理、可视化语录管理页与 AI Tools。

## 指令一览

均需带指令前缀（默认 `/`），以下指令仅适用于群聊。

| 指令 | 权限 | 说明 |
| --- | --- | --- |
| `/语录` | 全体 | 独立随机抽取一张本群语录，正常累计权重、去重与保底状态 |
| `/语录投稿 [标题]` | 受投稿权限控制 | **回复一条含图消息**投稿；标题可选 |
| `/撤回投稿 [名称]` | 投稿人本人 | 撤回自己的投稿；不带名称撤回自己最新一条，也可回复 bot 语录卡片撤回 |
| `/语录状态` | 全体 | 查看本群数量、投稿权限与戳戳冷却 |
| `/语录查看 <名称>` | 管理员 | 直接查看指定语录及投稿人、投稿时间；不影响随机/保底状态 |
| `/投稿权限 <0\|1\|2>` | 管理员 | 设置投稿权限：0 关闭 / 1 仅管理员 / 2 全体成员 |
| `/戳戳冷却 <秒>` | 管理员 | 设置本群戳一戳触发语录的冷却时间 |
| `/语录调试 <0\|1\|2>` | 管理员 | 查看或设置**本群**调试模式：0 关闭 / 1 写入日志 / 2 日志 + 卡片附注 |
| `/语录删除 [名称]` | 管理员 | 删除语录；可回复 bot 的语录卡片后不带参数使用 |
| `/语录改名 <旧名称> <新标题>` | 管理员 | 重命名语录；回复 bot 卡片时仅填写 `<新标题>` |
| `/语录改稀有 <名称> <1-6>` | 管理员 | 修改星级（1~6★）；回复 bot 卡片时仅填写 `<1-6>` |
| `/语录拉黑 @用户\|UID` | 管理员 | 全局禁止目标投稿与抽卡查看语录 |
| `/语录解封 @用户\|UID` | 管理员 | 解除全局语录黑名单 |

### 回复式管理示例

机器人发出一张包含“您抽到了……”或“恭喜抽到……”的语录卡片后，可直接回复该卡片：

```text
/语录删除
/语录改名 杰克的新奇妙比喻
/语录改稀有 6
/撤回投稿
```

插件会从被回复卡片的图片/文件名解析本群语录，避免手动输入文件名。`/撤回投稿` 仍会校验投稿归属，只允许撤回自己的投稿。

### 投稿说明

投稿必须回复图片消息：

```text
回复图片后发送：/语录投稿 杰克的奇妙比喻
```

图片自动保存为 `3.<标题>.<扩展名>`（默认落在最低**可抽**档 3★；1★/2★ 默认不参与抽卡，可在管理页调整）。未提供标题时使用投稿时间命名。标题（含扩展名）与已有语录重名时会拒绝投稿。

投稿成功后请确认截图为正确的聊天记录；如投稿有误，可使用 `/撤回投稿 <名称>` 或回复 bot 语录卡片发送 `/撤回投稿`。

## AI Tools

插件会向 AstrBot Agent 注册以下语录工具，AI 可在当前群聊天中按需要调用：

- `quote_list`：按星级（1~6★）筛选、分页查看语录列表和投稿信息
- `quote_view`：查看指定语录详情
- `quote_draw`：使用正常权重、去重与保底状态抽卡
- `quote_status`：查看本群统计
- `quote_submit`：对用户回复图片投稿
- `quote_delete`、`quote_rename`、`quote_set_rarity`、`quote_revoke`：语录内容管理
- `quote_configure_group`、`quote_configure_global`、`quote_manage_blacklist`：群设置、全局设置和黑名单管理

AI 的工具权限与命令权限一致：删除、改名、改稀有度、群/全局设置、黑名单等管理操作仅 bot 管理员可执行；AI 不会返回图片的本地绝对路径。被语录系统拉黑的用户不能通过 AI 绕过查看、抽卡或投稿限制。

工具的列表、查看、管理结果会直接返回给 Agent，供 AI 继续判断和回复；`quote_draw` 会主动把与 `/语录` 完全一致的图片卡片发送到群内，并向 Agent 返回“已完成抽卡并发送到群内。”。

## WebUI 配置与管理页面

插件配置既可在 AstrBot 插件配置弹窗中调整，也可在插件详情页的 `admin` Page 中调整。两处使用同一份运行时设置；**语录管理也在这个 `admin` 页面里**（表格形式，见下）。

可调项目包括：

- 默认投稿权限模式
- 默认戳戳冷却时间
- 戳一戳发送语录的概率
- 随机去重窗口（同一星级内最近 N 抽不重复；填 `0` 关闭去重）
- 星级权重（每次抽取先按权重决定星级、再在该星级内均匀抽图，因此权重占比就是出率；填 `0` 表示该星级不会被抽到）。默认按明日方舟同款：6★ 2%、5★ 8%、4★ 50%、3★ 40%，2★/1★ 默认 0（只作分类保留）
- 1~6 星保底：每 N 抽必出一次对应星级，填 `0` 禁用；默认每 10 抽必出一次 6★。本群没有该星级或更高星级图片时保底不生效，计数保留，等有图后立即触发
- 投稿 JSONL 日志查看与群号过滤

以下项目按群单独保存，在 Page 的「按群调试模式」区填写群号后设置，群内管理员也可直接用指令或让 AI 调整：

- 投稿权限模式、戳戳冷却（`/投稿权限`、`/戳戳冷却`）
- 调试模式（见下）

## 调试模式

调试模式**按群生效**（存在该群的 `settings.json` 里，与投稿权限、戳戳冷却同级），用于确认“这一次到底按什么概率抽的、是不是保底出的”。共三档，可在群内 `/语录调试 <0|1|2>`（管理员）、WebUI Page 的「按群调试模式」区（填群号后保存），或 AI 的 `quote_configure_group`（`debug_mode` 参数）里切换：

| 档位 | 行为 |
| --- | --- |
| `0` | 关闭（默认） |
| `1` | 每次抽卡把「出货计数」一行写入 AstrBot 日志（`[语录调试] 群…`） |
| `2` | 除日志外，再把同一行附注在语录卡片文字上方（群内可见） |

群内附注（档位 `2`）是固定的三行，随后才是正常的抽卡卡片：

```text
[语录调试]
出货计数：6★4 5★17 4★98 3★73 2★8 1★0
6★ 2.0(2)% 5★ 8.5(8)% 4★ 49.0(50)% 3★ 40.5(40)%
★★★★
标题.jpg
[图片]
```

日志里同样三行的前两行，并在首行带上群号与来源：`[语录调试] 群123456789｜来源=指令 /语录 用户=10001`。

- `出货计数` 是**各星级累计抽到的次数**，与保底计数无关：保底只决定“这一抽抽到什么”，计数如实按抽到的星级累加。
- 第三行是 **`实际(设定)%`**：实际＝该星级计数 / 总抽数，设定＝该星级权重 / 权重总和。只列出「设定权重非 0」或「已有出货」的星级，0 权重档不刷屏。
- 需要清空重新统计时，在 `admin` 页的「语录管理」里点「清零出货计数」（只清零统计，不动保底计数、去重与图库）。
- 指令抽卡、戳一戳抽卡、AI 的 `quote_draw` 三条路径共用同一套输出，且只使用**发起抽卡那个群**的调试档位。
- `/语录状态` 会一并显示本群当前调试档位。

## 语录管理（admin 页内）

`admin` Page 里的「语录管理」区就是可视化表格（不单独占用一个 Page，因为 AstrBot 只加载默认页面）：

- 填**群号**后点「查询」；可按**星级**（6★~1★）、**关键词**（标题或文件名）、每页条数筛选。
- **点击表头排序**：标题 / 星级 / 投稿人 / 投稿时间 / 大小，再点一次切换升/降序。
- 表格每行：缩略图（点击看大图）、标题、星级下拉、投稿人、投稿时间、大小、**改名**、**删除**。
  缩略图由后端用 Pillow 压成 160×120 的 JPEG 并**内嵌成 data URL**（插件页 iframe 与 dashboard 隔离、拿不到它的 cookie，直接 `<img src="/api/...">` 会被鉴权拦住）；点缩略图会通过 bridge 取完整图在弹层里预览。
  - 改**星级下拉**＝立即把这一张改名到该档（文件名前缀随之变化，投稿记录同步）。
  - **改名**只改标题，保留星级与扩展名；重名会被拒绝。
- 批量：勾选多行后「应用到选中」；或「当前筛选全部设为该档」把当前筛选结果一次性改档
  （适合把迁移后落在 2★/1★ 的老卡片批量提到 3★ 以上）。
- 「清零出货计数」把本群累计出货统计归零（不影响保底、去重与图库），方便重新核对概率。
- 页面顶部显示当前权重对应的出率（如 `★★★★★★ 2%`）；改权重/保底在同一个页面的「全局设置」区。

> 缩略图走插件扩展路由 `GET /quote_collocter/quotes/image`，由 AstrBot 用 dashboard 登录态鉴权后返回图片；
> 浏览器无法直接读取服务器上的文件系统路径（如 `/root/astrbot/data/...`），所以必须经这个接口。

## 数据存储

```text
data/plugin_data/quote_collocter/
├─ settings.json             # 全局设置、保底、黑名单
├─ submit.log                # JSONL 投稿日志
├─ .rarity_scale             # 稀有度刻度迁移标记（1..5 → 1..6 星）
└─ <群号>/
   ├─ settings.json          # 群级投稿权限、冷却、调试模式与戳戳状态
   ├─ order.json             # 抽卡状态：保底计数、最近抽到、累计出货计数
   └─ <稀有度>.<标题>.<扩展名>
```

语录图片按群隔离存储，更新/重装插件不会丢失数据。

## 本地测试

插件自带一套**不需要 AstrBot** 的测试（`tests/` 目录，纯标准库）：

```bash
# 一键自检：语法 + 配置 + WebUI 脚本 + 全部测试
bash tests/run_tests.sh

# 全部测试（72 个用例）
python3 -m unittest discover -s tests

# 只跑抽卡概率模型（出率、去重、保底、状态文件兼容性）
python3 tests/test_draw_probability.py

# 只跑插件功能（指令、按群调试、投稿全流程、AI Tools、Web API）
python3 tests/test_plugin_logic.py
```

`tests/stub_astrbot.py` 是最小 AstrBot 桩（消息组件、`filter` 装饰器、`Star`/`Context`、`astrbot.api.web`、`logger`），
它让 `main.py` 能在本地被导入并调用真实 handler；测试会在临时目录里建图库和 data 目录，不污染仓库。

## 注意事项

- 图片投稿没有内容限制，请自行审核。
- 管理页缩略图依赖 Pillow（AstrBot 自带 `pillow>=11.2.1`）；若运行环境没有 Pillow，管理页显示「无预览」，其余功能不受影响。
- 从 1.0 升级到 1.1 时首次启动会做一次稀有度迁移（图片前缀 +1、投稿日志与抽卡状态同步），群多时可能多花几秒；之后由 `.rarity_scale` 标记跳过。
- 戳一戳、引用消息读取及本地缓存下载仅 OneBot v11（aiocqhttp）平台支持。
- **某个群里只有管理员能用、普通成员发指令和戳一戳都没反应**时，先查 AstrBot 的 **ID 白名单**（配置 → 访问控制 → 白名单）：开启白名单且该群不在列表里时，消息在进入插件之前就被丢弃，指令与戳一戳一起失效；`wl_ignore_admin_on_group`（管理员无视群聊白名单）会让管理员仍然正常，容易误判成插件故障。把群号（或 `aiocqhttp:GroupMessage:<群号>`）加进白名单即可，打开 `id_whitelist_log` 后日志会打印 `is not in the session allowlist` 作为确诊依据。
- AI Tools 是否可用取决于 AstrBot 当前会话是否启用了 Agent/工具调用能力。
