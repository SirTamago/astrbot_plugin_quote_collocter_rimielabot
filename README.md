# AstrBot 群友语录插件

什么？群友又爆典了？当然是截图保存让他名垂千古口牙（

截图投稿群友的逆天语录，发送 `/语录` 或戳一戳机器人随机抽取一张。插件支持独立随机抽取（稀有度权重即出率）、保底、短期去重、投稿记录、回复式管理和 AI Tools。

## 指令一览

均需带指令前缀（默认 `/`），以下指令仅适用于群聊。

| 指令 | 权限 | 说明 |
| --- | --- | --- |
| `/语录` | 全体 | 独立随机抽取一张本群语录，正常累计权重、去重与保底状态 |
| `/语录投稿 [标题]` | 受投稿权限控制 | **回复一条含图消息**投稿；标题可选 |
| `/撤回投稿 [名称]` | 投稿人本人 | 撤回自己的投稿；不带名称撤回自己最新一条，也可回复 bot 语录卡片撤回 |
| `/语录状态` | 全体 | 查看本群数量、投稿权限与戳戳冷却 |
| `/语录查看 <名称>` | 管理员 | 直接查看指定语录及投稿人、投稿时间；不影响随机/保底状态 |
| `/投稿权限 <0\|1\|2>` | 管理员 | 设置投稿权限：0 关闭 / 1 仅管理员 / 2 全体成员 |
| `/戳戳冷却 <秒>` | 管理员 | 设置本群戳一戳触发语录的冷却时间 |
| `/语录调试 <0\|1\|2>` | 管理员 | 查看或设置**本群**调试模式：0 关闭 / 1 写入日志 / 2 日志 + 卡片附注 |
| `/语录删除 [名称]` | 管理员 | 删除语录；可回复 bot 的语录卡片后不带参数使用 |
| `/语录改名 <旧名称> <新标题>` | 管理员 | 重命名语录；回复 bot 卡片时仅填写 `<新标题>` |
| `/语录改稀有 <名称> <1-5>` | 管理员 | 修改稀有度；回复 bot 卡片时仅填写 `<1-5>` |
| `/语录拉黑 @用户\|UID` | 管理员 | 全局禁止目标投稿与抽卡查看语录 |
| `/语录解封 @用户\|UID` | 管理员 | 解除全局语录黑名单 |

### 回复式管理示例

机器人发出一张包含“您抽到了……”或“恭喜抽到……”的语录卡片后，可直接回复该卡片：

```text
/语录删除
/语录改名 杰克的新奇妙比喻
/语录改稀有 5
/撤回投稿
```

插件会从被回复卡片的图片/文件名解析本群语录，避免手动输入文件名。`/撤回投稿` 仍会校验投稿归属，只允许撤回自己的投稿。

### 投稿说明

投稿必须回复图片消息：

```text
回复图片后发送：/语录投稿 杰克的奇妙比喻
```

图片自动保存为 `1.<标题>.<扩展名>`。未提供标题时使用投稿时间命名。标题（含扩展名）与已有语录重名时会拒绝投稿。

投稿成功后请确认截图为正确的聊天记录；如投稿有误，可使用 `/撤回投稿 <名称>` 或回复 bot 语录卡片发送 `/撤回投稿`。

## AI Tools

插件会向 AstrBot Agent 注册以下语录工具，AI 可在当前群聊天中按需要调用：

- `quote_list`：按稀有度筛选、分页查看语录列表和投稿信息
- `quote_view`：查看指定语录详情
- `quote_draw`：使用正常权重、去重与保底状态抽卡
- `quote_status`：查看本群统计
- `quote_submit`：对用户回复图片投稿
- `quote_delete`、`quote_rename`、`quote_set_rarity`、`quote_revoke`：语录内容管理
- `quote_configure_group`、`quote_configure_global`、`quote_manage_blacklist`：群设置、全局设置和黑名单管理

AI 的工具权限与命令权限一致：删除、改名、改稀有度、群/全局设置、黑名单等管理操作仅 bot 管理员可执行；AI 不会返回图片的本地绝对路径。被语录系统拉黑的用户不能通过 AI 绕过查看、抽卡或投稿限制。

工具的列表、查看、管理结果会直接返回给 Agent，供 AI 继续判断和回复；`quote_draw` 会主动把与 `/语录` 完全一致的图片卡片发送到群内，并向 Agent 返回“已完成抽卡并发送到群内。”。

## WebUI 配置与管理页面

插件配置既可在 AstrBot 插件配置弹窗中调整，也可在插件详情页的 `admin` Page 中调整。两处使用同一份运行时设置。

可调项目包括：

- 默认投稿权限模式
- 默认戳戳冷却时间
- 戳一戳发送语录的概率
- 随机去重窗口（同一星级内最近 N 抽不重复；填 `0` 关闭去重）
- 稀有度权重（每次抽取先按权重决定星级、再在该星级内均匀抽图，因此权重占比就是出率；填 `0` 表示该星级不会被抽到）
- 1~5 星保底：每 N 抽必出一次对应星级，填 `0` 禁用；默认每 10 抽必出 5 星。本群没有该星级或更高星级图片时保底不生效，计数保留，等有图后立即触发
- 投稿 JSONL 日志查看与群号过滤

以下项目按群单独保存，在 Page 的「按群调试模式」区填写群号后设置，群内管理员也可直接用指令或让 AI 调整：

- 投稿权限模式、戳戳冷却（`/投稿权限`、`/戳戳冷却`）
- 调试模式（见下）

## 调试模式

调试模式**按群生效**（存在该群的 `settings.json` 里，与投稿权限、戳戳冷却同级），用于确认“这一次到底按什么概率抽的、是不是保底出的”。共三档，可在群内 `/语录调试 <0|1|2>`（管理员）、WebUI Page 的「按群调试模式」区（填群号后保存），或 AI 的 `quote_configure_group`（`debug_mode` 参数）里切换：

| 档位 | 行为 |
| --- | --- |
| `0` | 关闭（默认） |
| `1` | 每次抽卡把完整模型信息写入 AstrBot 日志（`[语录调试] …`） |
| `2` | 除日志外，再把简版信息附在语录卡片文字上方（群内可见） |

两种输出的内容（日志版比群内附注版多出「权重」与「出货后计数」两行）：

```text
[语录调试] 群123456789｜图库 29 张：5★×1 4★×1 3★×2 2★×5 1★×20
权重：5★3 4★5 3★8 2★4 1★2
本次出率：5★13.6% 4★22.7% 3★36.4% 2★18.2% 1★9.1%
抽取：权重抽中 2★ → 保底覆盖为 5★｜5★ 候选 1/1 张（去重窗口 8，排除 0 张）→ 5.a.jpg
保底：触发 5★（判定 3/3）
出货后计数：5★0 4★0 3★0 2★0 1★0
```

- **本次出率**只在“本群有图的星级”之间归一化，就是这一抽真实的星级概率分布。
- **抽取**一行显示权重原本抽中的星级、是否被保底覆盖、该星级去重后的候选张数与最终命中的文件。
- **保底**一行显示哪个档位触发、判定用的计数（`距上次出该星级的抽数/阈值`）；某档已达阈值但本群没有该档及以上图片时会标注“已达阈值但本群无该档及以上图片（计数保留）”。
- 指令抽卡、戳一戳抽卡、AI 的 `quote_draw` 三条路径共用同一套调试输出，且只使用**发起抽卡那个群**的调试档位。
- `/语录状态` 会一并显示本群当前调试档位。

## 数据存储

```text
data/plugin_data/quote_collocter/
├─ settings.json             # 全局设置、保底、黑名单
├─ submit.log                # JSONL 投稿日志
└─ <群号>/
   ├─ settings.json          # 群级投稿权限、冷却、调试模式与戳戳状态
   ├─ order.json             # 抽卡状态：保底计数、最近抽到记录
   └─ <稀有度>.<标题>.<扩展名>
```

语录图片按群隔离存储，更新/重装插件不会丢失数据。

## 版本更新

> 版本号说明：本仓库是自用 fork，把 fork 时的上游 `v2.1.1` 记为自用线 **0.1** 基线，
> 之后按两位数字递增（0.2、0.3、1.0…）。上游历史版本保留在下方备查。

### 0.3
- 新增**按群调试模式**（`/语录调试 <0|1|2>`、WebUI Page「按群调试模式」、AI `quote_configure_group` 的 `debug_mode`）：可把每次抽卡的图库构成、权重与实际出率、去重候选、保底判定与是否命中写入日志，档位 `2` 还会在语录卡片上附注简版信息。档位存在群级 `settings.json`，只影响该群；`/语录状态` 与 AI 状态查询会显示本群档位。
- 新增两个 Web API：`GET/POST /quote_collocter/group-debug`（按群查询/保存调试模式）。
- 保底计数钳制在阈值以内，本群暂时缺该档图片时显示为 `N/N`，不再无限增长。

### 0.2
- 抽卡改为**每次独立随机**：先按稀有度权重抽星级（权重占比即该星级出率）、再在该星级内均匀抽图；不再使用「一轮内每张各出一次」的洗牌队列，因此每次抽取之间没有任何关联。
- 保底修复：此前保底计数每次抽卡都会被清零，默认的「每 10 抽必出 5 星」实际从未触发；现在按「距上次出该星级」正确计数与重置，且本群没有该星级或更高星级图片时不消耗计数，等有图后立即触发。
- 稀有度权重填 `0` 现在表示该星级不会被抽到（此前会被当成 `1.0`，等于没设）。
- 短期去重改为「同一星级内最近 N 抽不重复」：不再影响星级出率，也不会因为窗口大于图库而失效；只有 1 张图的星级无法避免重复；窗口填 `0` 可关闭去重。
- 抽卡状态文件 `order.json` 现在保存 `since`（保底计数）与 `recent`（最近抽到），旧格式文件可直接兼容。

### 0.1（自用线基线）

## 注意事项

- 图片投稿没有内容限制，请自行审核。
- 戳一戳、引用消息读取及本地缓存下载仅 OneBot v11（aiocqhttp）平台支持。
- AI Tools 是否可用取决于 AstrBot 当前会话是否启用了 Agent/工具调用能力。
